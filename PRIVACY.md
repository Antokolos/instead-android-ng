# Политика конфиденциальности Instead-NG

**Дата:** 16 ноября 2026

Instead-NG — приложение для запуска игр на движке INSTEAD. Приложение не создаёт учётных записей, не показывает рекламу и не собирает персональные данные.

## Какие данные обрабатываются

- **Не собираются:** имя, email, телефон, контакты, местоположение, рекламные идентификаторы, данные других приложений.
- **Сетевые запросы:** приложение загружает каталог игр и игровые архивы с `instead-games.ru` и `nlbproject.com` по HTTPS. Передаются только стандартные заголовки HTTP-запроса; идентификаторы устройства и пользователя не передаются.
- **Локальные данные:** настройки приложения, сохранения игр и скачанные игры хранятся только на устройстве пользователя, в приватных каталогах приложения (app-specific storage). Они не передаются разработчику.

## Разрешения

- `INTERNET` — загрузка каталога и игр.
- `ACCESS_NETWORK_STATE` — проверка доступности сети.
- `WAKE_LOCK` — экран не гаснет во время игры.

## Передача третьим лицам

Данные не передаются третьим лицам. Загружаемый контент предоставляется публичными каталогами игр INSTEAD.

## Удаление данных

Все локальные данные удаляются вместе с приложением. Отдельного удалённого профиля не существует.

## Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные о детях.

## Изменения

Актуальная версия политики публикуется по этому адресу. Дата изменения указана в начале документа.
